# Design Brief: ML Code Explainer

## Problem
Beginners feel intimidated by dark, hacker-terminal interfaces. The current design creates anxiety rather than comfort.

## Solution
A warm, inviting interface that feels like a friendly tutor's desk — clean, organized, and encouraging.

## Experience Principles
1. **Warmth over intimidation** — Every visual choice should make a beginner feel welcome
2. **Clarity over density** — Generous spacing, logical grouping
3. **Progressive disclosure** — Setup tucked away, results unfold naturally

## Aesthetic Direction
- **Philosophy**: Scandinavian
- **Tone**: Friendly, calm, encouraging
- **References**: Linear, Notion
- **Anti-references**: Hacker terminals, neon dashboards

## Tokens
- Fonts: Poppins (display) + DM Sans (body) + JetBrains Mono (code)
- Colors: Warm naturals + soft indigo accent, light & dark modes
- Spacing: 8px base scale
- Radius: 6/10/14px (rounded, friendly)
- Shadows: Soft, large blur, low opacity
